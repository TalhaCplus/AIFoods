# AIFoods

Static marketing site for AIFoods, AI agents for restaurants (ordering, catering, revenue intelligence).

Plain HTML, CSS, and JS. No build step.

- `index.html` home
- `ordering-agent.html`, `catering-agent.html`, `revenue-intelligence.html` module pages
- `faq.html`
- `css/styles.css`, `js/main.js`

All brands, names, testimonials, and numbers are illustrative.

Run locally: open `index.html`, or `python3 -m http.server`.
